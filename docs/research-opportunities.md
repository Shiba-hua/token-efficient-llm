# 从研究地图到可证伪选题

[返回总论](00-overview.md) · [机制索引](../sources/coverage.md)

以下是主代理从文献冲突和缺口推导的研究判断，不是已经获得的新实验结论。排序以同质量向左、首轮证据成本和可复用成果为依据；环境安装不视为主要障碍，自研大型平台、数据建设与正式训练仍计入投入。

## 1. 优先比较的四类问题

| 候选问题 | 已有最近邻与失败证据 | 能区分新方法的最小实验 | 应积累的可复用成果 |
| --- | --- | --- | --- |
| 保留失败信号的任务状态压缩 | Complexity Trap、ReadAgent、AgentFold；摘要可能延长轨迹 | 固定模型/工具，遮蔽、摘要、可回读记忆与候选策略；外测任务族和全I/O | 可移植状态策略、带出处轨迹、环境复现配方 |
| 依据验证收益决定继续或停止 | DEER、BATS、L1、ReTool；试答/验证也耗费资源 | 在相同质量约束下比较硬预算、预算提示、动态停止；计入验证与重试 | 预算控制器、校准数据和失败模式 |
| 稀有难题仍可恢复的短轨迹学习 | 最短自训练、TokenSkip、DAST、GKD/OPD | 相同教师采样预算，比较短SFT、压缩、难度偏好与学生前缀监督 | 可审计轨迹和训练配方、跨题族分析 |
| 程序化工具结果选择 | LLMCompiler、PTC、tool search；控制流/依赖错误 | 固定任务，比较原样回传、确定性过滤、现成程序调用与候选介入策略 | 可复用工具适配器、成本事件与任务证据 |

前两项优先级较高，是因为可以先固定模型做机制实验，也能复用现成有状态环境。它们的低安装门槛不意味着论文容易：最近邻已相当强，必须解释新信号、泛化或失败恢复贡献。数学RLVR可以进入第三项，但仅有奖励减长度不足以区别已有研究。[07](07-prompt-context.md)、[08](08-harness-agents.md)、[04](04-sft-distillation.md)、[06](06-rlvr-agentic.md)

## 2. 模型应承担哪些角色

模型选择服务于可检验问题，不按跨论文数字做“当前最强”排名。下列名称用于接近原作、减少复现变量，不是未经硬件验证的运行承诺。

| 研究角色 | 起步选择与依据 | 必要对照 |
| --- | --- | --- |
| 单轮短链复现 | TokenSkip的Qwen2.5-7B/14B-Instruct，或DAST/Arora对应的R1-Distill-Qwen-7B | 同一checkpoint默认/简洁提示/最短SFT，保留难题分层 |
| 数学预算服从 | L1的DeepScaleR-1.5B作为原作复现对象 | 外部硬上限、未训练预算提示，不能只比更大不同模型 |
| 工具状态/停止机制 | 先用已能完成所选环境的开放工具模型或可记录完整usage的API模型 | 同模型同harness消融，再用另一模型族检验迁移 |
| 白盒软压缩/latent机制 | ICAE或CODI已经验证的小模型规模 | 相同解码预算、前处理/latent计算，不能只比可见文字 |
| 教师与独立评审 | 使用公开数据配方支持的教师；最终质量优先执行器 | 教师不见测试答案；judge与方法反馈隔离；教师费用另账 |

若小模型几乎无法完成环境，压缩实验会落入全错区，无法分辨机制。因此先测少量开发任务，确认有可分析的成功和失败，再定模型规模。实际显存、吞吐、可训练长度与批量需在目标机器预检；本轮文献重构没有执行服务器训练或硬件验收。

## 3. 为什么这能积累研究资源，而不只增加标注劳动

在研究风险相近时，本地图倾向于选择能留下**可复用方法、可靠训练信号、可复现实验接口和有外部使用价值的结果**的方向。一个只靠人工逐题重标、每换任务就重做的榜单，积累性较弱；一个能接入多个现成环境的状态/停止机制，可能被后续实验和实际系统重复使用。

这是资源积累的研究策略，不是资金回报预测。是否能带来项目、岗位、合作或资本支配能力，还需要使用者需求与外部采用证据；本地图没有这类实测。应将最早的可检验问题设为“谁愿意复用、在哪种任务确实节省”，避免把论文新意直接等同于商业价值。

## 4. 半自动与全自动研究共用的 idea 检查卡

人机讨论或自动Agent提出候选后，都填写同一张卡：

| 字段 | 必须回答 |
| --- | --- |
| 新变量 | 改变数据、目标、信息还是调用策略？其他变量如何固定？ |
| 最近邻 | 至少三个同问题方法；逐项说明自己的差异，不能只换名字 |
| 反例来源 | 哪篇原文的失败/冲突使这个问题值得研究？ |
| 质量约束 | 目标性能、允许差异和难题标准在测试前如何定义？ |
| 成本合同 | 全输入/输出、辅助模型、失败、训练与评测各如何计量？ |
| 否证条件 | 什么结果说明没有新贡献、只是弱基线或成本转移？ |
| 泛化与泄漏 | 按题族/仓库/环境怎么隔离，哪些污染仍未知？ |
| 最小交付 | 现成环境、真实轨迹、可重跑命令、原始逐题账与分析 |

先让研究系统交付这张可核查的卡，再启动昂贵实验。可以由人类选择候选，也可由Agent自动提出；两者都需要独立重复和原始证据。**本轮没有系统比较Codex与已发表自动科研框架，因而不宣称某个编排平台最优。** 文献地图和上述卡可以作为两种流程共同输入，避免先自研完整科研平台。
