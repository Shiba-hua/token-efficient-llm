# 从研究地图到可证伪选题

[返回总论](00-overview.md) · [机制索引](../sources/coverage.md)

以下是主代理从文献冲突和缺口推导的研究判断，不是已经获得的新实验结论。排序以同质量向左、首轮证据成本和可复用成果为依据；环境安装不视为主要障碍，自研大型平台、数据建设与正式训练仍计入投入。

## 1. 优先比较的五类问题

以下最小实验是研究建议，尚未执行。先固定任务、模型、判分和完整成本记录，再逐个改变机制；不要同时升级模型、提示、工具与训练数据。

| 候选问题 | 最近邻与尚缺证据 | 最小区分实验 | 否证条件与资源 |
| --- | --- | --- | --- |
| 保留失败信号与出处的状态压缩 | [Complexity Trap](chapters/07-context/reference/2508.21433.md)、[MEM1](chapters/08-agents/reference/2506.15841.md)、[LightMem](chapters/07-context/reference/2510.18866.md)；单轮压缩率不能解释任务轮数 | 固定一个已有软件/检索环境，比较观察遮蔽、摘要、带出处回读与候选策略；按是否需要历史错误线索分层，计入摘要和回读 | 若相同成功率的总 I/O 无改善，或收益只来自删掉失败任务，则否证。可先只做现成模型推理，训练随后决定 |
| 依据验证收益停止搜索 | [Snell](chapters/06-reasoning/reference/2408.03314.md)、[DeepConf](chapters/06-reasoning/reference/2508.15260.md)、[L1](chapters/05-posttraining/reference/2503.04697.md)；验证也有费用，置信度会失配 | 同模型比较固定预算、简洁/预算提示、原方法停止器和候选信号；开发集定阈值，测试集按难度报告多预算曲线与尾部 | 加上验证成本后收益消失，或困难题只是更早放弃，即否证。需要可取得 logits/usage 的推理接口，先不训练大模型 |
| 短轨迹训练是否学到预算利用策略 | [The Art](chapters/05-posttraining/reference/2602.20945.md)、[最短正确自训练](chapters/01-data/reference/2502.20122.md)、[TokenSkip](chapters/05-posttraining/reference/2502.12067.md)、[DAST](chapters/05-posttraining/reference/2503.04472.md)；平均缩短与高预算潜力可能冲突 | 固定教师采样量与学生初始化，比较短 SFT、表达压缩、难度偏好和效率 RL；同时测低/中/高预算、正确/错误长度和多次采样成功率 | 候选只在一个预算点有效、训练投入不对齐，或高预算损失抵消目标收益，则不能声称整条前沿改善。先用小模型开发，再按目标 GPU 预检可训练长度 |
| 程序化控制流与工具观察选择 | [ReWOO](chapters/08-agents/reference/2305.18323.md)、[LLMCompiler](chapters/08-agents/reference/2312.04511.md)、[ReTool](chapters/05-posttraining/reference/2504.11536.md)；提前规划可能缺反馈 | 固定工具与执行器，比较逐步决策、依赖图执行、确定性结果过滤和候选介入策略；按可预知依赖/需观察修正分组 | 只击败冗长弱基线，或省下提示却增加重试，则否证。优先复用现有 harness，保留事件流，不先自建整个平台 |
| 上游目标怎样改变达到同样质量的推理长度 | [MTP](chapters/02-pretraining/reference/2404.19737.md)、[Rho-1](chapters/03-midtraining/reference/2404.07965.md)、[LCM](chapters/02-pretraining/reference/2412.08821.md)；现有能力证据不等于部署 token 证据 | 优先取得受控训练目标/检查点对照，固定普通自回归解码，绘制多预算任务曲线；把草稿加速关掉，分开测能力和生成长度 | 若仅 FLOPs/训练损失改善，或不同模型/数据混杂无法排除，则没有回答该问题。可用公开受控小模型或有限继续训练做机制实验；从头大模型训练不作默认起点 |

前两项的优先级来自首轮证据成本与可复用性，并非预计论文一定更容易。第三项最近邻密集：The Art 已系统比较数据、奖励与优化，“GRPO 加长度惩罚”需要进一步指出新增机制。第五项保留上游研究入口，同时正面暴露当前证据缺口。

## 2. 模型应承担哪些角色

模型选择服务于可检验问题，不按跨论文数字做“当前最强”排名。下列名称用于接近原作、减少复现变量，不是未经硬件验证的运行承诺。

| 研究角色 | 起步选择与依据 | 必要对照 |
| --- | --- | --- |
| 单轮短链复现 | TokenSkip 的 Qwen2.5-7B/14B-Instruct，或 DAST 对应的 R1-Distill-Qwen-7B | 同一checkpoint默认/简洁提示/最短SFT，保留难题分层 |
| 数学预算服从 | L1 的 DeepScaleR-1.5B，或 The Art 的公开小模型设置作为原作对照 | 外部硬上限、未训练预算提示，不能只比更大不同模型 |
| 工具状态/停止机制 | 先用已能完成所选环境的开放工具模型或可记录完整usage的API模型 | 同模型同harness消融，再用另一模型族检验迁移 |
| 白盒软压缩/latent机制 | ICAE或CODI已经验证的小模型规模 | 相同解码预算、前处理/latent计算，不能只比可见文字 |
| 教师与独立评审 | 使用公开数据配方支持的教师；最终质量优先执行器 | 教师不见测试答案；judge与方法反馈隔离；教师费用另账 |

若小模型几乎无法完成环境，压缩实验会落入全错区，无法分辨机制。因此先测少量开发任务，确认有可分析的成功和失败，再定模型规模。实际显存、吞吐、可训练长度与批量需在目标机器预检；本轮文献重构没有执行服务器训练或硬件验收。

## 3. 为什么这能积累研究资源，而不只增加标注劳动

在研究风险相近时，本地图倾向于选择能留下**可复用方法、可靠训练信号、可复现实验接口和有外部使用价值的结果**的方向。一个只靠人工逐题重标、每换任务就重做的榜单，积累性较弱；一个能接入多个现成环境的状态/停止机制，可能被后续实验和实际系统重复使用。

这是资源积累的研究策略，不是资金回报预测。是否能带来项目、岗位、合作或资本支配能力，还需要使用者需求与外部采用证据；本地图没有这类实测。应将最早的可检验问题设为“谁愿意复用、在哪种任务确实节省”，避免把论文新意直接等同于商业价值。

## 4. 半自动与全自动研究共用的 idea 检查卡

人机讨论或自动Agent提出候选后，都填写同一张卡：

| 字段 | 必须回答 |
| --- | --- |
| 新变量 | 改变数据、目标、信息还是调用策略？其他变量如何固定？ |
| 最近邻 | 至少三个同问题方法；逐项说明自己的差异，不能只换名字 |
| 反例来源 | 哪篇原文的失败/冲突使这个问题值得研究？ |
| 质量约束 | 目标性能、允许差异和难题标准在测试前如何定义？ |
| 成本合同 | 全输入/输出、辅助模型、失败、训练与评测各如何计量？ |
| 否证条件 | 什么结果说明没有新贡献、只是弱基线或成本转移？ |
| 泛化与泄漏 | 按题族/仓库/环境怎么隔离，哪些污染仍未知？ |
| 最小交付 | 现成环境、真实轨迹、可重跑命令、原始逐题账与分析 |

先让研究系统交付这张可核查的卡，再启动昂贵实验。可以由人类选择候选，也可由Agent自动提出；两者都需要独立重复和原始证据。**本轮没有系统比较Codex与已发表自动科研框架，因而不宣称某个编排平台最优。** 文献地图和上述卡可以作为两种流程共同输入，避免先自研完整科研平台。
