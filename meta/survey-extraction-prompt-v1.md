# 综述分类与候选提取任务 v1

只读取任务指定的一篇综述（核实固定版本不晚于2026-09-09），提取与推理时性能—token曲线相关的分类、原始参考文献及证据边界。不自行阅读参考文献正文，不派生代理，不修改公开仓库或执行Git；只写指定临时目录。你不独占工作环境，不覆盖其他人的文件。

目标是用更少推理时token维持性能；训练FLOPs/每token计算/费用/延迟另列。不要用泛化的训练效率工作填充预训练章节。间接路径可列出具体联系与未测环节，不凭“可能”认定有效。

先看指定综述的摘要、分类图/目录和相关小节，再读取参考文献列表以核对准确标题、作者、年份、arXiv/DOI。不要凭模型记忆写ID。已覆盖的原始工作也可以列入候选，去重由主代理统一完成。

只输出 survey.json 与 brief.md：
- survey_id,title,version,source_url,date,actual_read_scope;
- routes: 问题、简短机制、与推理token的联系、相关章节（13章见主任务）、综述定位;
- candidates: title,authors,year,arxiv_id/doi/source_url（实际有才填）,survey_locator,route,role（起点/改进/竞争/反例/背景）,token_relevance（direct/indirect/compute_only）,reason;
- gaps/conflicts: 分类缺口、证据冲突、哪些只是训练效率、2026更新覆盖止于哪里。

优先提取8至15项对路线理解最有用的候选，而非罗列所有参考文献；若综述很广，可按明确缺口提供更多但不启动追读。首次首读只为候选规划，不输出貌似已经复核原论文的实验证据。

完成只回传文件位置及不超过250字摘要。无法取得原文就声明实际范围，不能把摘要读取报告为全文读取。
