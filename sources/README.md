# 阅读记录与证据索引

本目录保存第二版领域研究地图的公开来源记录。正文中的方法与实验判断应当能够回到这里，再定位到原论文的章节、表格或官方文档。研究地图的检索截止日为 **2026-09-09**；这不是穷尽文献的系统综述。

## 研究范围

首要问题是：在同一任务分布上，保持性能时，能否减少完成整项任务所用的模型输入与输出 token？小团队可负担的方法优先。提高极大推理预算下的性能上限是辅助问题。

成本标记采用以下含义：

| 标记 | 证据对象 | 可以支持的判断 |
| --- | --- | --- |
| T | 实测生成长度、输入长度或整项任务 token | 在论文给定口径与条件下的直接效率证据；局部 token 降幅不自动等于整项任务降幅 |
| I | 数据、训练或通用能力改进 | 可能间接改善部署效率；还需要预算曲线实验 |
| C | FLOPs、显存、吞吐、延迟、API 费用 | 相邻计算效率；不能直接写成 token 减少 |
| V | 企业公开产品或工程实践 | 说明提供或采用了什么；厂商实验不能充当独立复现 |

这些标记不是质量排序。同一来源可以拥有多个标记。任务 token、训练 token、tokenizer、隐藏推理、缓存和非文本表示需要分别记录。

## 检索与阅读方法

1. 以近期综述、成熟综述和公开研究索引发现路线；引用量与热度仅作发现线索。没有实际取得引用量的来源不标成“高引用”。
2. 对照不同综述的分类，追到原论文的方法、实验和局限；再检索关键前作、竞争方案、后续工作与反例。
3. 原文卡保留标题、来源、日期或版本、实际阅读范围、发现路径、机制、实验条件、结论和证据边界。只读摘要的工作不得填充具体实验结论。
4. 每条主要路线尽量覆盖起点、改进或竞争者、限制证据。少数新兴工作不能包装成成熟共识。
5. 主代理复核承载章节关键判断的来源和数字，统一分类并写作。Luna 只进行有边界的论文阅读与核查，不写最终综合结论，不操作仓库。
6. 按生命周期组织正文，同时按“少读、少写、少重试、少通信、训练换推理、改变表示”建立交叉索引。对跨阶段方法指定主要归属并交叉链接。

论文数字保留其模型、任务、预算与基线条件，不拼成跨论文排名。官方博客与文档用于公开方案证据；对未披露的训练算法和架构保持未知。视频和报告演讲只作补充阅读入口，其论断仍回到论文或可检查的实现。

## 综合判断与验收

正文分别使用“基础范式”“多方支持”“尚有争议/待验证”等措辞，并给出相称的证据。多个方法共用一个数据集、同一教师或同一研究团队时，不按完全独立证据计数。

研究机会由主代理从失败案例、相互冲突的结果和测量缺口中推导，明确标为分析判断。每章提供容易重复已有工作的想法及其最近邻文献，帮助读者在提出 idea 前查重。**这种内容设计本身不能证明 idea 重复率显著下降**；因果或统计显著性需要额外读者实验。

本项目使用 AI 辅助检索、阅读与写作。阅读记录描述实际完成的动作，不把搜索结果摘要、代理生成的总结或代码运行成功当作新的科研实验。
