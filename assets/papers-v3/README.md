图像用于与正文对应的学术讲解。优先取作者 LaTeX 工程的原始资产；嵌入式 TeX 图或不可直接取得的资产，在记录说明后渲染或从官方 PDF 截取。原始 PDF、署名与源版本保留，PNG 是 GitHub 预览。未用生成模型重画论文实验数据。

许可字段保留原文声明。arXiv 非独占分发条款不当作开放复用许可；未采用开放许可的原图保留原权利并逐图署名，作为学术图示引用呈现，不重新许可。具体复用应核对原来源。CC BY-NC-ND 资产保留完整内容，只作显示格式转换；其他 TeX 包装替换和 PDF 裁切有单独说明。
